The most useless superpower imaginable, in one line: the power to count every grain of rice in a bowl — but only after it has already been eaten. A perfect count of something that no longer exists, delivered at the exact moment it can help no one.

## Run it

```sh
node main.ts
```

It writes the one-line entry to `/output/entry.txt` (1–140 characters, UTF-8).
